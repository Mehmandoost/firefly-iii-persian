## About this repository

This is my **personal fork** of [Firefly III](https://github.com/firefly-iii/firefly-iii), a self-hosted personal finance manager. I use it for my own data with a focus on **Iran** and the **Persian (Jalali) calendar** in the UI.

It is not an official Firefly III project. I do not offer support or guarantee updates.

## What it is based on

[Firefly III](https://firefly-iii.org/) helps you track income, expenses, budgets, categories, and tags on your own server. For installation and general usage, see the [official documentation](https://docs.firefly-iii.org/).
